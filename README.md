# SmartPOS — Desktop Point of Sale System

SmartPOS is a Java-based desktop Point of Sale (POS) application designed for retail transaction processing, inventory management, and database record keeping.

---

## ??? Tech Stack & Requirements

* **Language:** Java (JDK 17 or higher recommended)
* **Build Tool:** Apache Maven
* **Database:** MySQL Server (via XAMPP or standalone MySQL Server)
* **Styling:** Custom CSS (style.css)

---

## ?? Prerequisites

Before running the application, ensure you have installed:
1. Java Development Kit (JDK 17+)
2. Apache Maven
3. MySQL Database / XAMPP

---

## ??? Database Setup

1. Start your MySQL Server.
2. Create a new database named smartpos:
   CREATE DATABASE smartpos;
3. Import the SQL file included in this repository (src/main/java/com/smartpos/smartpos.sql).
